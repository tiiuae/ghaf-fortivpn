# Code of conduct

This project is part of the Ghaf community and follows the
[Ghaf Code of Conduct](https://github.com/tiiuae/ghaf/blob/main/CODE_OF_CONDUCT.md).

Be respectful, constructive, and considerate in issues, pull requests, review,
and other project spaces. Conduct concerns can be reported to
`GhafCodeofConduct@ssrc.tii.ae`.
